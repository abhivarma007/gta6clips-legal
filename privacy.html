Last updated: 23 November 2026

GTA6 Clips Daily Uploader is a personal desktop tool that publishes videos to the operator's own TikTok account.

Data we access: when you log in with TikTok, the tool receives an access token, your TikTok open ID and your basic profile information (display name and username). It uses these only to upload videos you choose and to show the upload status.

Storage: tokens are stored only on the operator's own computer. They are never sold, shared or sent to any server other than TikTok's API.

Other users: the tool doesn't collect, store or process data about any other TikTok user.

Revoking access: you can revoke access at any time in TikTok under Settings → Security → Manage app permissions. Deleting the local token file also removes all stored data.
